# ReleaseChecker

Приложение предназначено для нахождения ошибок сборки медиа файлов и разнородных свойств потоков.  
Для диагностики используется доступ к метаданным файлам используя MediaInfo.

### Ошибки сборки, обнаруживаемые приложением:
- наличие forced флагов;
- наличие default флага не на первом потоке;
- отсутсвие default флага на первом потоке видео или аудио (субтитры могут быть без default);
- видеопоток занимает менее 50% контейнера[^1];
- размер аудиопотока больше трети размера видеопотока[^1];
- потоки на русском языке идут не первыми;
- наличие задержек контейнером[^2];
- наличие ошибок целостности;
- отличающаяся от видео длина потока;
- русские надписи не первые, при наличии;

### Предполагаемые ошибки сборки:
- наличие разных субтитров на одном языке с одним количеством строк;
- первые субтитры содержат больше строк, чем вторые (предполагается, что первые — надписи);

### Свойства потоков, проверяемые на схожесть:
- видео: ~~заголовок~~, кодек, битовая глубина, частота кадров, разрешение, соотношение сторон;
- аудио: заголовок, язык, кодек, конфигурация каналов;
- субтитры: ~~заголовок~~, язык, кодек.

> [!NOTE]
> Для всех свойств, кроме битрейта, подсвечиваются красным значения, отличные от большинства.  
> У битрейта подсвечиваются разными цветами значения, отличающиеся от среднего на 10-20-30-40-50%.

## Механика "упорядочивания" дорожек
В программе присутствует механика, упорядочивающая дорожки по столбцам, основываясь на заголовках дорожек.  
Механика срабатывает только в том случае, если упорядочивание можно сделать без смены порядка дорог.
